# Python and SQL Interview Preparation

## Overview
This repository contains Python and SQL interview preparation materials designed to strengthen programming, problem-solving, database management, and query-writing skills.

The questions are organized into separate Jupyter Notebook files for easy learning and practice.

## Repository Structure

```text
Interview Questions/
│
├── PYTHON TASK/
│   └── Python_Interview_Questions.ipynb
│
├── SQL TASK/
│   └── SQL_Interview_Questions.ipynb
│
└── README.md
```

## Topics Covered

### 1. Python Interview Questions
- Python fundamentals
- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists and dictionaries
- String manipulation
- Problem-solving programs

### 2. SQL Interview Questions
- SQL fundamentals
- SELECT statements
- WHERE and ORDER BY
- Aggregate functions
- GROUP BY and HAVING
- JOIN operations
- Subqueries
- Database queries

## Requirements
- Python 3.x
- Visual Studio Code
- Jupyter Notebook extension
- Python and SQL fundamentals

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Jupyter extension.
4. Open the required `.ipynb` notebook.
5. Select a Python kernel.
6. Execute the cells using **Run All** or `Shift + Enter`.

## Learning Objectives
- Improve Python programming skills.
- Practice SQL queries and database concepts.
- Develop logical and analytical thinking.
- Prepare for technical interviews and coding assessments.
